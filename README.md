# Claude AI Agent CRM

A CRM with a Claude-powered AI agent, built on Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting started

```bash
pnpm install
cp .env.example .env.local   # add your ANTHROPIC_API_KEY
pnpm dev
```

Open http://localhost:3000.

## Scripts

- `pnpm dev` – start the dev server
- `pnpm build` – production build
- `pnpm lint` – run ESLint
